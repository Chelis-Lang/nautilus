Prepare Nautilus 0.7.47 on published Chelis 0.18.12. Nautilus's seven sampling exports now take an explicit affine key instead of the removed `Random` effect, and large Bessel coefficients have explicit source widths so `Nautilus.Special` checks under the new compiler. `Nautilus.Core.version()` now returns the exact package-version string instead of the placeholder integer `1000`. Gamma, chi-squared, and Student-t sampling still have the known constant-gamma defect (nautilus#84). See nautilus#83 and chelis#2413.
